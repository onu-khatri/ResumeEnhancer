- Public example gallery
- Category landing page
- Public asset detail or preview page

## Design Token Guidance

- Public discovery pages should feel lighter and more editorial than the app workspace. A distinct public tone signals that the visitor is still in the acquisition experience rather than the product itself.
- Use generous spacing and stronger imagery than internal/productive screens, while keeping CTA clarity high. Editorial whitespace and visuals build confidence, but the call-to-action must remain visually dominant.
- ATS/trust labels should be informative, not alarmist. Labels like "ATS-friendly" should explain their meaning in plain language rather than pressure or confuse the visitor.

## Edge Cases

- Visitor lands directly on a filtered category URL that now has no results. The page must render an honest empty state with nearby alternatives rather than a broken or misleading grid.
- Public asset exists but was downgraded from free to premium in app. The public card should not promise free access; continuation must reflect the asset's current in-product availability.
- Example content is discoverable but not directly clonable. The UI should clarify that an example is guidance, not a one-click clone, so expectations stay aligned with behavior.

## Testing Focus

- SEO-route and client-filter consistency. URL-driven filters must produce the same result whether loaded server-side for crawlers or client-side for users.
- CTA continuity into signup/template start flow. The chosen asset and its source context must survive the hand-off into onboarding.
- Mobile filter usability. Collapsible filters or chip scrollers must remain usable on small screens without hiding key controls.

## Developer Notes

- Keep public asset cards presentation-safe and independent from internal admin fields. Public components must consume only the public projection so internal metadata can never render.
- Use stable slugs and route params so public pages can support search indexing and campaign links. Stable identifiers are required for SEO durability and marketing link integrity.
