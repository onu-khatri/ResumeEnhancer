# Research — Cover Letter Builder With Resume-Aware Start Flow

## Why This Story Exists

Both selected competitors publicly treat cover letters as meaningful companions to resumes, not optional leftovers. Novorésumé positions matching cover-letter templates as a premium feature (Basic: "No Cover Letter"; Premium: "Matching Cover Letter"). Resume Now promotes a full cover-letter builder. AI-assisted cover-letter generation is a natural extension of the resume AI domain.

## Business Interpretation

- Cover letters help move the platform from "resume tool" toward "application package platform."
- Novorésumé gates cover letters as **premium-only** — a clear signal that matching resume+cover-letter is a commercial differentiator.
- **Resume-aware start** (AI pulls from resume data) reduces duplicate data entry and improves completion.
- **Shared visual design** between resume and cover letter templates creates a "matching package" that feels professional and is premium-valued.
- AI cover-letter generation is a natural extension of the AI domain — if the platform already has resume-context AI, adding cover-letter AI has low incremental complexity.

## Requirement Implications

- Cover letters should share enough model/design system logic with resumes to feel like a connected, matching package.
- Resume-aware start (pull contact info, name, target role from resume) reduces user effort.
- AI-assisted cover-letter creation fits naturally into this domain and should reuse the same AI patterns as resume AI (reviewable suggestions, no fabrication, quota tracking).
- Premium gating (if applicable) must be clear before the user invests effort.

## Risks If Under-Specified

- Cover letters may feel bolted on, lowering perceived product quality.
- Users may need to re-enter information already in their resume, creating frustration.
- Template/style cohesion between resume and cover letter may be lost if they use separate design systems.
- AI may generate cover-letter content that contradicts resume facts if context linking is weak.

## Recommended Scope Interpretation

- Treat cover letters as a connected extension of the main workflow, with shared templates/themes.
- Focus MVP on resume-linked start, manual editability, matching design continuity, and optionally AI generation.
- If premium-gated, apply the same "preview but don't download" or "free format, paid design" logic as the resume.

## Open Questions

- MVP scope: manual editor, AI-assisted, or both?
- Premium-gated like Novorésumé (Basic = no cover letters), or part of a larger premium bundle?
- Should cover-letter and resume templates be paired one-to-one (matching sets) or selectable independently?
- Should AI cover-letter generation use the same quota/credit system as resume AI?
